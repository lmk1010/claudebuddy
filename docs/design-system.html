01 · brand

一颗火花，一个提示符

应用图标 = Claude 的手剪火花 + 右下角一个终端提示符 >_。火花说明它为谁服务，提示符说明它是什么。除此之外不加任何元素：不加字、不加渐变、不加光。

08 · session

会话 · 主工作台

95% 的时间都在这一屏。终端不再是一块黑板，而是跟应用同一色系定制的纸面：比主区亮半档、靠发丝线和软影浮起来，语法色按纸面重调。右栏是检查器：节奏、上下文、本次改动。

中栏就是终端，不再单独悬浮整栏一块同色纸面，标签条只用一条发丝线和下划线选中态；没有第二道边框、没有投影，不会套框。
右栏是检查器，不是仪表盘不堆白卡片；四段用发丝线分开，每段一个等宽眉标。节奏用 24 根分钟柱 + 阈值虚线，比进度条多说一倍。
标题行用衬线项目名 19px 衬线，分支、状态都退成小字；右上“终端 / 改动”切视图，不再堆一排无名图标。

15 · motion & material

快、准、按压有分量

参数全部实测自 Claude Desktop 的 MainWindowPage.css（251 KB，1021 个 --cds-* 变量）。结论先说：质感不来自特效，来自时长极短、曲线手调、按压有回弹这三件事。

时长：五档，不是一档

以前全站写 120ms，那是"一档走天下"，结果微交互发飘、面板发急。CDS 分了五档，每档对应一类动作：

档位值用在哪为什么是这个数
--dur-fast60ms按下、图标换色压手感必须 <100ms，否则像"慢慢地缩"
--dur-snap120ms底色 / 边框 / 文字色主力档。超过 150ms 就有延迟感
--dur-base200ms入场、展开、淡入要看清"东西从哪来"
--dur-sheet300ms抽屉、右栏开合大面板移动距离长，需要更多时间
--dur-slow450ms只给弹簧复位这段长，是因为回弹要看得见

曲线：三条手调 + 一条真弹簧

用 ease / ease-in-out 关键字是廉价的直接原因——那是浏览器默认观感，一眼能认出"这是个网页"。

曲线值性格
--ease-outcubic-bezier(0,0,.2,1)进：快出发、慢落定。绝大多数情况用它
--easecubic-bezier(.32,.72,0,1)主力：出得急、收得稳
--ease-overshootcubic-bezier(.34,1.3,.64,1)轻微过冲，给胶囊、角标、徽标
--springlinear(0,.2459,.6526,.9468,1.0764,1.0915,1.0585,.9993,.9914,.9921,.9957,.9988,1)真弹簧：14 个采样点，峰值 1.0915（过冲 9.15%）后回落收敛
弹簧跟 cubic-bezier 的回弹不是一回事。cubic-bezier 只能让速度先冲过头； linear() 让位移本身超过 1 再回来。这就是"按下有分量"和"按下去抖了一下"的区别。 这也是老版本设计稿里「禁止弹簧回弹」那句要改掉的原因——CDS 本身就在用弹簧，只是用得极克制。

按压：一长一短，才叫手感

CDS 的按压原子 .cds-btn-squish 只有两条声明，但方向是反的，不能合并：

按住不动 · 60ms 硬收敛
按下
transition: transform 60ms ease-out;
transform: scale(.975)
松手 · 450ms 弹簧复位
松开
transition: transform 450ms var(--spring);
transform: scale(1)

常态挂长弹簧（为了松手那一下过冲），按下换 60ms ease-out（为了手指一压立刻陷进去）。两段都换成弹簧、或都换成 ease-out，这个手感就没了。

元素缩到说明
按钮 / 行 / 输入 chip.975面积小，缩 2.5% 才看得见
卡片.99面积大，1% 就够；再多会像"陷进去"
圆形发送键.94圆的缩放最明显，单独收一档

入场：位移不超过 4px

场景做法时长
主区内容分层入场透明度 0→1 + 上移 4px，问候 / 输入框 / 建议 / 最近 依次错开 40ms200ms
最近卡片逐个跟上同上，每张再错 30ms200ms
弹层 / 菜单 / 命令面板translateY(4px) + 淡入；面板可 scale(.98→1)200ms
侧栏新会话行高度 0fr→1fr 展开（不用 max-height 猜数字）200ms

执行态：三点脉冲，暗态留残影

CDS 的 .cds-dot 是 1.8s linear 无限循环，三颗各差 0.2s，且暗态是 .2857 而不是 0。留残影，三个点才像"一队在跑"；归零就变成"一灭一亮"，像坏掉的指示灯。本应用只有单点指示，做单点呼吸，光圈从 3px 涨到 5px、透明度同步降。

滚动边缘渐隐

内容被边缘截断时用渐变柔化，不让字被窗口硬切。CDS 走 animation-timeline: scroll()，零 JS、跑在合成线程、滚动时不掉帧。本应用同样实现，且起点不淡顶部、终点不淡底部——两个边缘宽度抽成可插值变量（需 @property 注册成 <length>），由滚动位置插值。

已实测确认不支持的一条：设计稿早前还抄了 CDS 的 grad 字重轴（font-variation-settings:"grad" 180）。实测本机打包的 Anthropic Sans 只有 wght 轴、没有 grad 轴（写入后渲染宽度完全不变），已从实现里删掉，不留死代码。字重仍然用 CDS 的 580/600。

发丝线：边框按屏幕倍率收敛到物理 1px

「边框看着细腻」的真正来源不是颜色浅，而是物理宽度。CSS 的 1px 在 2x 屏上占 2 个物理像素，视觉上比设计稿粗一倍——这是网页感很重的一处细节。

CDS 的做法是按屏幕倍率把线宽压到物理 1px：

屏幕--hair物理占位
1x1px1 像素（不变）
2x（Mac 全系）0.5px1 像素
3xcalc(1px / 3)1 像素
4xcalc(1px / 4)1 像素

所以所有 1px 边框都写 var(--hair)，不要硬写 1px。用了之后，同一个界面在普通屏和 Retina 上看起来是一样细的。

焦点环与 hover：两套反馈不叠加

CDS 的 hover 选择器一律带 :not(:focus-visible)——键盘聚焦时不该再叠一层鼠标悬停的底色，否则会出现"焦点环 + 悬停底色"两层同时亮，看着像控件卡住了。本应用同样处理。

字重：580 而不是 600

这是最容易被忽略、但对"质感"影响最大的一条。CDS 的四档是 400 / 500 / 580 / 600——semibold 是 580，bold 是 600。可变字体上写 600/700 会让字明显发胖发闷，屏幕上一排"胖字"是廉价感的头号来源。

焦点环：四段叠加，不是一圈硬描

outline: 2px solid 是浏览器默认观感。CDS 的 --cds-focus-shadow 叠四层：

inset 0 0 0 1px var(--cream), /* 先用底色把控件自身边缘隔开 */
0 0 0 1px var(--coral), /* 再描一圈品牌色 */
0 0 6px 1px rgba(204,120,92,.28) /* 外面补一层柔光 */
